# Bolt vs Later ⚡

*Beat procrastination, one tiny win at a time.*

A 10-episode animated YouTube series. **Bolt**, a tiny caped hero with a lightning-bolt antenna, fights **Lord Later**, a sleepy purple cloud king who whispers "do it later…". Each 2.5–3 minute episode follows the same arc:

> relatable struggle → Lord Later's trick → the real psychology → 3 "weapons" (practical techniques) → victory → recap → a one-line mission for the viewer.

Everything (art, animation, voices, music, sound effects) is generated by the code in this folder, so the channel owns all of it.

## What's in `output/`

| Folder / file | Contents |
|---|---|
| `videos/ep01.mp4` … `ep10.mp4` | Final 1080p30 videos, H.264 + AAC, loudness-normalised to −14 LUFS (YouTube standard) |
| `thumbnails/epNN_thumbnail.jpg` (+ `.png`) | 1280×720 thumbnails, under 2 MB |
| `descriptions/epNN_description.txt` | Copy-paste title, description (with chapters and sources), tags, pinned comment |
| `UPLOAD_KIT.md` / `youtube_metadata.json` | The same metadata for all episodes in one place |

## Rebuilding / making new episodes

```bash
pip install skia-python piper-tts numpy scipy pillow fonttools faster-whisper
pip install --no-deps num2words
# voices: download en_US-ljspeech-high and en_US-bryce-medium (.onnx + .onnx.json)
# from huggingface.co/rhasspy/piper-voices and point PIPER_VOICES at that folder
export PIPER_VOICES=/path/to/voices

python make.py durations      # synthesize voices, print episode lengths
python make.py preview 3      # still frame for every beat of episode 3 -> build/preview
python make.py render 3       # full video -> output/videos/ep03.mp4
python make.py thumbs         # all thumbnails
python make.py metadata       # titles, descriptions, chapters, tags
```

An episode is just a list of "beats" in `episodes/epNN.py`, for example:

```python
dict(scene="fight", weapon="clock", tag="WEAPON #1", name="SET A 2-MINUTE TIMER", hp=0.66, hit="ZAP!",
     say="Weapon one: set a *two minute timer*. ...")
```

Scenes: `title`, `struggle`, `later`, `talk`, `stat`, `compare`, `fight`, `win`, `list`, `outro`.
Words wrapped in `*asterisks*` are highlighted yellow in the captions. Add `tts="..."` to a beat to spell a hard name phonetically for the voice.

## Licensing notes

- **Voices:** Piper TTS models `en_US-ljspeech-high` (Bolt, trained on the public-domain LJ Speech dataset) and `en_US-bryce-medium` (Lord Later, released into the public domain by its author). Both are safe for a monetised channel. Each line is synthesised up to 4 times, and a speech-recognition check keeps the clearest take.
- **Music & sound effects:** synthesised from scratch in `engine/audio.py`, so there's no Content ID risk.
- **Fonts:** Luckiest Guy (Apache 2.0), Fredoka (OFL), via Google Fonts.
- **Art & animation:** drawn procedurally in `engine/` (skia).

# Season 2 (adults): VS LATER 🌑

A darker, adult rework inspired by minimalist "discipline arc" animation: **less narration, more action**.

- **You:** a plain cream-coloured everyman with determined brows (a black hoodie outdoors).
- **LATER:** your shadow self. It's the same body in black with a red glow, slit eyes and a smirk, and it offers pizza, phones, the gaming chair... and fights back.
- Dark, flat sets (a night room with a snowy window, a gym grid, a blizzard hill over the city, night streets, dawn), letterbox bars, film grain, and **DAY counters**.
- About 75–95 narrated words per episode (deep, calm narrator; LATER whispers in red). The ideas land through big on-screen lines, fights, chases, climbs and montages, all cut on the beat of a synthesized dark score.
